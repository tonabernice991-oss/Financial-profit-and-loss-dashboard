# 📊 Financial Profit and Loss Dashboard

This project demonstrates how Microsoft Excel can be used to analyze business financial performance by organizing data, calculating results, and visualizing insights using dashboards and charts.

## 🚀 Project Features
- Organized financial data management
- Automatic calculation of:
  - Total income
  - Total expenses
  - Net profit or loss
- Interactive dashboard with charts
- Clear financial summaries for decision making

## 🛠 Skills & Tools Used
- Microsoft Excel
- Excel formulas (SUM, IF, logical functions, etc.)
- Data organization techniques
- Dashboard and chart creation
- Financial data analysis

## 📂 Project Structure
- **Input Sheet** – Enter financial data (income & expenses)
- **Calculation Sheet** – Automated calculations
- **Dashboard Sheet** – Visual charts and financial summary

## ▶ How To Use
1. Download the Excel file from this repository.
2. Open it using Microsoft Excel or compatible software.
3. Enter financial data in the input section.
4. View automatic calculations and dashboard insights.

## 📊 Output
- Total income
- Total expenses
- Net profit or loss
- Visual financial dashboard for analysis

## 🧠 What You Will Learn
- Financial data analysis using Excel
- Logical and mathematical Excel formulas
- Creating dashboards and charts
- Data-driven decision making
